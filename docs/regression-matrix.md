## Checked by hand, and why

- **NAV-04** The back stack and typed drafts survive the system killing the process in the background. Needs a real process kill (adb shell am kill) and relaunch from recents; recreation in a test does not exercise saved-state serialisation across processes.
- **PUSH-02** Firebase Cloud Messaging delivers to the prod build, in foreground, background and after a cold start. Needs a Firebase project and a physical or Play-services device; the prod flavor's config file is not in the repository.
- **OFFL-01** Losing and regaining the radio mid-session on a real device recovers without restarting the app. Fault injection covers each request failing; toggling a real radio (airplane mode) mid-flow is checked by hand.
- **A11Y-01** The main flow is usable with TalkBack and at the largest font size. Content descriptions are asserted in tests, but a screen-reader walkthrough is a judgement call made by a person.
